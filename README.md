# Kiji

Kiji is a static site generator framework for .NET.

## Projects

- `src/Kiji`: core SSG runtime, routing, rendering, feed, sitemap, and dev server
- `src/Kiji.Markdown`: markdown content pipeline and extensions
- `src/Kiji.Images`: responsive image generation support
- `src/Kiji.Tests`: unit and integration tests for the Kiji stack

## Build

```powershell
dotnet build
```

## Test

```powershell
dotnet test
```
